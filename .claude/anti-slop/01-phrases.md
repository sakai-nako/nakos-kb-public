# 撲滅すべき語彙・フレーズ

AI が好んで使う日本語フレーズの一覧と、置換の方向性です。網羅的な辞書ではなく、**頻出かつ無自覚に使われがちなもの**に絞っています。

> 全部を機械的に置換するのは逆効果。**文脈ごとに「これは書き手の声か、LLM の既定か」**で判断する。書き手が意図して使っている場合は残す。

[02-structures.md](./02-structures.md)（構造）、[03-tropes.md](./03-tropes.md)（包括的トロープ）と併せて参照。

---

## 1. 大げさな昇華語

小さな体験を「真理」「美学」に昇華させる名詞化。AI は何でも「教えてくれること」にしたがる。

| Slop                         | 置換の方向                                         |
| :--------------------------- | :------------------------------------------------- |
| 「○○が教えてくれること」    | 削る or 「○○をやってわかったこと」「○○を見て思ったのは」 |
| 「○○から学んだこと」        | 具体的な行動変化に書き換え（「次から○○するようにした」） |
| 「本質」「真理」「核心」    | 削る or 具体の言い換え                             |
| 「美学」「哲学」「境地」    | 削る or 場面の描写で代替                           |
| 「○○の風景」「○○の景色」    | 「○○の現場」「○○のとき」に降ろす                  |
| 「タペストリー」「ランドスケープ」「エコシステム」 | 具体名で置換                       |

### 例

- ❌ 「失敗が私に教えてくれることがあった」
- ⭕ 「失敗したあと、次から朝のレビューを入れるようにした」

## 2. AI 常套副詞

修辞のための副詞。なくても意味が通るなら削る。

- 「静かに」「深く」「根本的に」「実に」「まさに」
- 「興味深いことに」「驚くべきことに」「示唆に富む」
- 「ある意味で」「言わば」「いわゆる」（多用時のみ）
- 「実は」「実のところ」「正直に言えば」（メタコメント化しているとき）

### 例

- ❌ 「これは静かに、しかし根本的に開発体験を変えた」
- ⭕ 「これでビルド時間が 40 秒短くなった」

---

## 3. 空虚な動詞句

主語が何をしたかをぼかす言い回し。

- 「役割を果たす」「機能する」「位置づけられる」
- 「象徴する」「体現する」「具現化する」
- 「〜となっている」（受動気味の状態表現）
- 「〜という側面がある」

### 例

- ❌ 「このツールは開発フローにおいて重要な役割を果たす」
- ⭕ 「このツールでテスト実行が並列化された」

---

## 4. メタコメント / 過剰なシグナリング

「ここで重要なのは」「実はここがポイント」のような、読者の注意を強制的に引こうとする前置き。本当に重要なら、内容で伝わる。

- 「ここで興味深いのは」「ここで重要なのは」
- 「注目すべきは」「特筆すべきは」
- 「実はここがポイントで」「肝心なのは」
- 「言うまでもなく」「もちろん」
- 「結論から言うと」（記事の冒頭で 1 回ならよいが、節ごとに繰り返さない）

### 例

- ❌ 「ここで重要なのは、テストが落ちた理由が flaky ではなかったということだ」
- ⭕ 「テストが落ちた理由は flaky ではなかった」

---

## 5. 冗長な前置き / 自己言及

- 「私たちは○○を考える必要がある」 → 「○○を考える」「○○が要る」
- 「○○について議論することは重要だ」 → 議論しないでいきなり論じる
- 「この記事では○○について書きたい」 → タイトル・冒頭の主張で示す
- 「○○とは何だろうか」（修辞的疑問の冒頭） → 答えから書く

---

## 6. AI 由来の翻訳調

英語 LLM 由来の直訳調が日本語に混じる場合。

- 「〜することができる」 → 「〜できる」
- 「〜を行う」 → 動詞 1 語に圧縮（「実装を行う」→「実装する」）
- 「〜という事実」 → 削る or 「〜こと」
- 「〜の文脈において」 → 「〜では」「〜のとき」
- 「〜とも言える」 → 削る（断言を避ける逃げ）

---

## 7. 英語混入時の頻出語

英語が混じる文章でよく出る LLM 既定語。日本語に降ろすか、別語に置換。

| Slop          | 置換                                       |
| :------------ | :----------------------------------------- |
| delve         | dig into / look at / 「掘る」              |
| utilize       | use / 「使う」                             |
| leverage      | use / 「使う」「効かせる」                 |
| robust        | sturdy / reliable / 「壊れにくい」         |
| streamline    | simplify / 「ならす」「無くす」            |
| tapestry      | mix / 「組み合わせ」                       |
| landscape     | space / scene / 「界隈」「分野」           |
| serves as     | is / 「である」                            |
| harness       | use / 「使う」                             |
| ecosystem     | 文脈次第（道具一式 / 業界）                |
| paradigm shift| change / 「やり方が変わる」                |

---

## 8. 三点リーダー・記号系の語彙

純粋な語彙ではないが、フレーズ的に出るので。

- 「〜の一言に尽きる」「〜と言わざるを得ない」 → 削る or 言い換え
- 「〜なのかもしれない」（多用時） → 立場が弱いサイン。断言できる箇所は断言する
- 「〜にほかならない」 → 大げさ。削る
