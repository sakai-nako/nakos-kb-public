# 媒体別アダプタ — ブログ記事

[00-core.md](./00-core.md) の 5 軸を、ブログ記事 (`src/content/blog/`、`content-external/articles/`) に翻訳します。コアを置き換えず、ブログ固有の Slop パターンとユーザー既存スタイル規約との整合を足します。

---

## ブログ固有の頻出 Slop パターン

### タイトル

- ❌ 「○○が私に教えてくれたこと」 — [01-phrases.md](./01-phrases.md) §1 の典型
- ❌ 「○○について考える」 — 主張なし
- ❌ 「○○入門」「○○まとめ」（独自視点なし） — 検索コンテンツの劣化版に見える
- ⭕ 主張・困り事・固有の場面を入れる

### リード（冒頭 1〜2 段落）

- ❌ 「最近、AI が話題になっています。本記事では…」 — 既知の前置き + メタ宣言
- ❌ 「私たちは○○について考える必要があります」 — 立場ゼロ、主体ぼかし
- ⭕ 困り事 1 行代弁から入る（[storytelling/10-blog.md](../storytelling/10-blog.md) と連動）
- ⭕ 自分の固有の場面から入る（「先週の PR レビューで、○○と思った」）

### 締め

- ❌ 「結論として、○○は重要だ」 — シグナルポスト + 主張なし
- ❌ 「最後に、私たちは○○を続けていく必要がある」 — 主体不在
- ⭕ 今日の自分が次にやることを書く（「明日の朝会で○○を試す」）
- ⭕ 残った問いを誠実に書く（「これでも△△は解けていない」）

### 本文

- 段落 3 つ連続で「○○ではなく△△」が来たら危険信号
- 全段落の最後が「○○なのだ」「○○である」で締まっているとリズム消失
- 太字始まりの箇条書きが 3 リスト連続なら 1 つは普通の箇条書きに崩す

## ブログ向け 5 軸チェックリスト

| 軸     | チェック                                                       |
| :----- | :------------------------------------------------------------- |
| 立場   | タイトルだけで主張がわかるか / 反論する人を想像できるか        |
| リズム | 短い段落・長い段落が混ざっているか / 締めの文末が単調でないか |
| 主体性 | 「私」「自分」が具体的な行動の主語として出ているか            |
| 具体性 | 数字・固有名詞・場面が 3 つ以上あるか                          |
| 削減   | 「もう書いた」が出てくる箇所はないか / 同じ主張を 3 回言ってないか |

## 既存スタイル規約との整合（重要）

このリポジトリのユーザーには既に確立された文体規約がある。anti-slop は**それらを上書きしない**。並列で適用する。

### ベタ詰め

[rules/17-writing-style.md](../rules/17-writing-style.md) §1 に基づき、本文は英数字・強調 `**...**` 前後の半角スペースを入れない。

- `30 分` → `30分`、`CfP を` → `CfPを`、`**地続き** です` → `**地続き**です`
- 例外: 英語フレーズ内 (`SRE Kaigi`)、行頭リスト/見出しマーカー、em-dash `—`・矢印 `→` 等の構造的区切り

これは Slop チェックとは**独立した軸**。Slop レビューで本文を整形しても、ベタ詰めは維持する。

### 女装・ニッチ趣味は「個性」枠で扱う

[rules/17-writing-style.md](../rules/17-writing-style.md) §5.1 に基づき、女装や趣味を扱うときに**「弱みの開示」「告白」「実は隠していた」という枠で書かない**。

- ❌ 「実は私には言いづらいことがあった。それは…」
- ❌ 「弱みだと思っていたものが武器になった」（「武器になった」の構造自体が AI Slop と相性が良いので二重に危険）
- ⭕ 「○○の話を最初から普通にする」「私の場合は○○」と平場で書く

AI は「課題 → 克服」「弱み → 強み」型のナラティブに寄せる傾向が強い。**このパターンが出てきたら警戒**してユーザーに確認する。

### 存命作曲者・実在曲の扱い

[rules/17-writing-style.md](../rules/17-writing-style.md) §5.2・§4 に基づき、

- 自分の地の文で実在の存命作曲者に言及するときは敬称を付ける（呼び捨て NG）
- 実在曲を「物語の道具」として従属させない（「○○の曲が差し出された」「○○を借りた」のような言い回しを避ける）

これは Slop 軸ではなく**事実関係・敬意の問題**。レビュー時に固有名詞が出てきたら同時にチェックする。
