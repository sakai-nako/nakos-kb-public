# 共通コア — AI Slop 対策

媒体（ブログ／発表資料／SNS／CfP abstract）を横断する「AI Slop 検出と修正の観点」を 1 枚に集約したコアファイルです。媒体別アダプタ（[10-blog.md](./10-blog.md) / [20-slides.md](./20-slides.md)）と [slop-review Skill](../skills/slop-review/SKILL.md) はここを起点に動きます。

> 「型にはめる」ためではなく、「どの観点で迷っているかを名指しできる」ようにするためのものです。全部を毎回埋める必要はありません。

---

## AI Slop とは

LLM の既定の声が透けて見える文章の総称。書き手の体重が乗っておらず、判型の予測可能性が高い状態です。次のような兆候があります。

- 主張が抽象的で、誰でも書ける一般論で終わる
- 全段落が同じ長さ・温度・着地点
- 「X ではなく Y」「3 つの観点」「ここで重要なのは」など定型構造の反復
- 大げさな名詞化（「教えてくれること」「本質」「美学」「境地」）
- 装飾の過剰（em-dash 多用、bold 開始の箇条書き、→の濫用）
- 誰の体験か曖昧（「私たちは…と感じる」「読者は…だろう」）

**AI を使うこと自体は悪ではない**。問題は、LLM の生成した既定の声をそのまま公開してしまうこと。下書きを LLM に手伝わせるのは前提として、公開前にここで挙げる観点で削り、書き手の固有性を戻す。

---

## 5 軸スコアリング

各軸を 1〜10 で見立てる。合計 **35/50 未満**は書き直し or 大幅修正の検討対象。

数値そのものは判定ツールではなく、対話のフックとして使う（「立場 6/10、削減 4/10 ですね」と言って、どこから直すか相談する）。

| 軸                  | 問い                                                   |
| :------------------ | :----------------------------------------------------- |
| **立場 (Stance)**       | 反証可能な具体的主張があるか。「誰がどう反論できるか」が見えるか |
| **リズム (Rhythm)**     | 段落の長さ・トーン・着地点に揺らぎがあるか             |
| **主体性 (Agency)**     | 誰が何をしたかが明示されているか。傍観者的な書き方になっていないか |
| **具体性 (Specificity)**| 抽象語で終わらず、固有名詞・数字・体感・場面まで降りているか |
| **削減 (Density)**      | 削れる箇所はないか。同じ主張を 10 通りに言い換えていないか |

### 軸ごとの典型的な低スコア兆候

- **立場が低い**: 「○○が大切」「バランスが重要」のように反論する余地のない一般論
- **リズムが低い**: 全段落 3 文・全部「である」調・全段落の最後がオチで締まる
- **主体性が低い**: 主語が「私たち」「読者」「業界」など漠然としている
- **具体性が低い**: 数字・名前・場面がなく、抽象名詞だけで進む
- **削減が低い**: 結論を 3 回繰り返す、同義反復、メタコメント過剰

---

## 修正優先順位

スコアが低くても、上位レイヤーから直すと下位は連動して改善する。**上から順に効く**ので、語彙や記号より先に立場・主体・構造を見る。

1. **立場** — 主張を反証可能にする / 削る判断を入れる
2. **主体** — 誰がやったか / 何を感じたかを名指しする
3. **構造** — 否定的並列・修辞的疑問・三連畳みを崩す
4. **語彙** — 撲滅語を具体語に置換 ([01-phrases.md](./01-phrases.md))
5. **記号・装飾** — em-dash / →／bold 開始 / 全角ダッシュ削減

語彙だけ直しても、立場が抽象的なままだと AI 臭は残る。逆に立場が立っていれば、語彙の Slop はかなり許容される。

---

## 対象外メディア

- **小説** ([src/content/novels/](../../src/content/novels/)): 文体・反復・断片化・独白は意図的な作家性。novel-revision の領分（[90-principles.md](./90-principles.md) で再強調）
- **コードコメント・技術 doc 内部・frontmatter**: 機械可読性が優先。装飾削減と一部の語彙チェックだけ部分適用
- **対話・会議メモの逐語記録**: 元発話の癖を残す方が価値が高い
